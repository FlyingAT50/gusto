# Gusto UK — first strong iteration

A responsive, dependency-free homepage and brand-story page built from the existing approved Gusto UK assets.

## Preview

Run a local static server in this directory, then open `index.html` through that server.

## Structure

- `index.html` — cinematic homepage, range switcher, technology, heritage and dealer journey
- `about.html` — editorial brand-story page with a careful, factual racing timeline
- `styles.css` — complete responsive design system
- `script.js` — navigation, scroll/reveal motion and bike-platform switcher
- `assets/` — imagery already in use on the supplied Gusto UK deployment

The build deliberately uses no framework or third-party JavaScript, keeping it portable and quick to integrate into the existing Replit project.
